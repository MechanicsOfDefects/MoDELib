Cai source quadrature accuracy on polycrystal saved frames
=========================================================
Date: 2026-10-31. Core radius a=2 in Burgers-vector units.
Current sampling: UniformOpen, quadPerLength=0.1. Source and target geometry
is straight (DislocationSegment inherits SplineSegment<dim,0>).

Build: cmake --build build --target benchmarkCaiQuadratureAccuracy -j4
Run: OMP_NUM_THREADS=12 OMP_PROC_BIND=false build/tests/benchmarkCaiQuadratureAccuracy tutorials/polycrystal 1000 1024
Arguments: tutorial folder, frame, number of sampled targets (default 1024).

Method:
- Select 1024 evenly spaced indices from the actual mobility target array at
  the original density. Keep exactly these targets fixed for every density.
- Sum unscreened analytical StraightDislocationSegment over every unique nonzero-Burgers
  network segment, including stationary/boundary sources. No periodic images,
  applied stress, FEM correction, line tension, or screening in either sum.
- Compare with the six-component particle sum at source densities
  0.1, 0.2, 0.4, 0.8, 1.6. Geometry and Burgers vectors are identical.
- Relative L2 = sqrt(sum_target ||error||_F^2 / sum_target ||reference||_F^2).
  Pointwise percentiles use ||error||_F/max(||reference||_F,1e-30).
  Absolute errors are in normalized stress units (shear modulus).
- Near contribution includes segments whose closest point is within 10*a of
  the target. Near/far error norms are normalized by the TOTAL reference norm;
  they are not relative errors of the near/far fields themselves and do not add.
- Source construction and stress evaluation are repeated, but no simulation is
  advanced. Saved frames and tutorial files remain unchanged. A temporary copy
  of inputs supplies fmmTreeDepth=2 in DefectiveCrystal.txt as required currently.

Findings:
At source density 0.1, aggregate error is 35.91% (frame 0) and 37.73% (frame 1000).
Frame-1000 median pointwise error is 0.689%, p95 29.92%, max 68.97%.
Nearly all aggregate error comes from the near-segment contributions.
Uniform refinement is not monotonic for under-resolved near-core targets:
frame-1000 aggregate error increases to 59.53% at density 0.2 before falling.
At density 1.6 aggregate errors are 0.111% and 0.0961%, respectively; frame-1000
worst sampled target still has 1.126% error, with 908995 source particles.
These are sampled-target observations, not bounds over all targets or frames.

The existing analytical segment method does not have this source quadrature
error; its quadPerLength sets mobility evaluation/integration points. Reusing
that density for source integration is a new approximation. No production
physics has been switched to it. Uniform source density 0.1 is not an adequate
replacement. Near-field refinement or analytical local correction should be
validated before deployment, rather than globally multiplying source count.

CPU timing comparison (2026-10-31)
==================================
Frame 1000, same 1024 targets, 4182 nonzero-Burgers physical segments,
12 CPU threads. Analytical: OpenMP static parallel loop over targets and
existing StraightDislocationSegment::stress. Particles: Kokkos OpenMP target loop.
Seven alternating-order measurements after warmup; medians reported.
Identical unscreened physical problem and core a=2. No construction, upload,
download or accuracy-diagnostic work included in timing.
The current benchmark reproduces this comparison for each source density.
Analytical evaluation costs about 41-44 ms. Uniform particle sampling at
density 1.6 costs 680 ms (16.15x) for aggregate error 0.0961%.
These are direct all-source CPU sums, not FMM or Ewald performance.
