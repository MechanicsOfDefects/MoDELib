Lazar short-range cutoff study
==============================
Build target: benchmarkLazarCutoff
Usage: benchmarkLazarCutoff tutorial frame [targets=1024]
Kokkos OpenMP, 12 threads. Same source/target sampling as the existing Cai/Lazar
benchmarks. Physical length ell=2, numerical screening length h=8 in Burgers
units. Source density 0.1, 1024 targets at evenly spaced array indices.
No neighbor lists: each test still scans all sources and applies a spherical
particle-distance cutoff. Retained fraction is not a timing speedup.
No periodic replicas, FEM corrections, external fields, or FMM.
Production force evaluation is unchanged.

Reference: untruncated short-range particle stress. Truncated total stress is
short_truncated + long_untruncated; its error equals short_truncated-short_full.
relative_short = sqrt(sum_target ||error||_F^2 / sum_target ||short_full||_F^2).
relative_full = sqrt(sum_target ||error||_F^2 / sum_target ||full||_F^2).
max_absolute = largest target Frobenius error.
max_over_full_rms = max_absolute / sqrt(sum_target ||full||_F^2 / target_count).
This last metric is NOT a maximum pointwise relative error.
All nine matrix entries are included, counting symmetric off-diagonals twice.
A full=short+long reconstruction check is required before reporting errors.

These measurements isolate particle cutoff error. They do not validate the
source quadrature density, accuracy for other networks/parameters, or infinite
periodic-image summation. Provisional cutoff 12h: aggregate error <=1.19e-5,
max error / full RMS <=1.08e-4, retained pairs 0.0501--0.0690 percent for these
two frames. No universal error tolerance or production default is set here.
