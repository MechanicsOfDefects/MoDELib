Update 2026-11-03: cached translations and experimental near interpolation
=========================================================================
The baseline measurements below are retained as historical reference.
New default: Lazar M2L caches seven geometric/material coefficients for each
interpolation-node pair, shared by box level and integer displacement.
This factors the tensor mapping instead of storing 54 entries per node pair.
The cache budget is 256 MiB; excess classes use the original kernel evaluation.
setTranslationCacheBudget(0) disables it. Kernel type/ell/h/material changes
invalidate the cache; source-strength changes do not. The cache belongs to the
geometry plan and is recreated on plan rebuild, not shared between time steps.
First evaluation includes cache construction; steady-state medians exclude it.
General kernels without the prepared-translation interface remain uncached.

setInterpolateNear(true) enables experimental SOURCE interpolation in near
leaves, using exact target positions and existing source moments. Leaves with
no more than p^3 particles still use direct summation. Default remains FALSE.
This is not an accuracy-controlled near-field accelerator. The tutorial's
coarse leaves do not resolve h=8: combined relative RMS errors are 65--76%.
Therefore this option must NOT be enabled for production on these inputs.
Even the broad-screen synthetic fixture only converges slowly; smoothness
alone does not guarantee accuracy at low order with signed tensor sources.
More local refinement or a separately validated near representation is needed.
No change to production forces, periodic correction, or the physical core.

Validation: all four stress/FMM/neighbor regression tests pass, including
cached/uncached agreement, budget fallback, changed kernel parameters, constant
and cubic near interpolation reproduction, Lazar order convergence, and
switching back to direct near evaluation. Approximation accuracy is reported
separately from these implementation checks. No GPU measurements.

Benchmark: same frame 0 and 1000 fixtures, 1024 targets, depth 2, ell=2,h=8,
rc=96, 12 OpenMP CPU threads, nine repetitions after the first call.
mode=0: uncached M2L + direct near; mode=1: cached M2L + direct near;
mode=2: cached M2L + experimental interpolated near.
upward/downward/near_last_ms are stage timings of the LAST repetition, not
stage medians; median_ms is the median complete evaluation time.
setup_ms excludes lazy cache preparation, which is included in first_ms.
Short-range evaluation and initial sampling/uploads remain excluded.
At order 4, cached M2L reduces the downward stage roughly from 11 to 4--5 ms.
The direct near stage remains about 66--85 ms and dominates total evaluation.
The faster experimental near result is inaccurate and is not a usable speedup.

Historical baseline (before the above changes)
==============================================
Kokkos interpolation stress FMM
===============================
Implementation: include/FMM/KokkosStressFMM.h
KokkosStressFMM<ExecutionSpace> plan(execution, tree, sourcePositions,
                                  targetPositions, interpolationOrder);
plan.evaluate(execution,kernel,sourcePositions,sourceTensors,targetPositions,
              outputStresses,sourceCount,targetCount);

Free-space only. No implicit periodic image summation, periodic root operator,
or zero-mode choice. Do not substitute this for the periodic long-range field
until that separate operator is implemented and validated. The short-range
neighbor evaluator separately supports active periodic directions.
Production forces have NOT been switched to this path.

Uses the existing BoxTree geometry and BoxParticleIndex assignment, without
modifying the network, junction ownership, or periodic topology. Sources and
targets remain distinct arrays. Chebyshev-Lobatto tensor interpolation of
order p=2..6 means p^3 nodes per box. Nine source-tensor coefficients and six
symmetric stress coefficients per interpolation node.

Passes:
 P2M: source tensors deposited with cardinal interpolation weights.
 M2M: child coefficients transferred to parent cardinal basis.
 M2L: actual long-range stress kernel evaluated between interpolation nodes.
 L2L: parent local stress interpolated to child nodes.
 L2P: local stress interpolated to target positions.
 Near: exact direct LONG-range kernel for unresolved neighboring leaf pairs.
The near contribution is required in addition to the short-range cutoff sum.
No near-field interpolation compression or approximate exponentials yet.
No compressed/cached M2L matrices yet: kernel translations are evaluated each
call. This is a baseline FMM, not a fully optimized implementation.

A dual box traversal accepts pairs when center distance exceeds 1.01 times
the same-level box diagonal; otherwise it descends both boxes or adds a
leaf near pair. Physical sphere separation is used for rectangular roots.
Empty source/target boxes are pruned. Each source-target pair contributes
at one accepted level or through near evaluation, never both.

Plan construction builds geometry, lists, weights, and device arrays.
Rebuild on ANY source/target motion, reordering, topology, or tree change.
Tree revision changes are detected; same-sized particle movement cannot be
detected from the device views. Tree must outlive the plan. Source tensor
strengths can change without rebuilding geometry; moments and locals reset
on every evaluation. Plans own mutable work arrays, are noncopyable and must
not be evaluated concurrently. Evaluation fences before returning.
Memory scales with all uniform-tree boxes times p^3, not just occupied boxes;
large depth/order combinations can consume substantial memory.

Validation: kokkosStressFMM plus caiStressParticles, lazarStressParticles,
shortRangeParticleNeighbors all pass. Constant-field conservation checks
interaction coverage and transfer partition of unity. Depth 0 equals direct.
Random signed tensor sources test order convergence (depth 2 order 2 error
0.0680, order 4 0.00230, order 6 9.72e-5), depth 3 multilevel passes, endpoints,
coincident source/target convention, repeat/reset, changed strengths, empty
sources, invalid order, and stale tree rejection. These checks use the same
regularized particle model as the direct sum.

Benchmark target: benchmarkLazarFMM tutorial frame [targets=1024] [repeats=9]
Measured on M2 Max, Kokkos OpenMP 12 CPU threads, 1024 target samples,
source density 0.1, ell=2,h=8, rc=12h, depth 2, five timed calls after warmup.
Setup includes lists, interpolation weights, device allocation/upload.
median_ms includes all FMM evaluation passes, including exact long near field.
Direct long-range reference is a single timed all-pair call. Source/target
sampling and their initial upload are outside both measurements.
relative_long = aggregate RMS error / direct long-range RMS.
relative_total compares FMM long + cutoff short with direct FULL Lazar stress.
max_error_over_long_rms is a worst absolute target error divided by aggregate
long-range RMS, not maximum pointwise relative error. Short-range neighbor
construction/evaluation is NOT included in the FMM timings. The total error
includes the cutoff error but does not measure source quadrature error.
These figures do not yet establish end-to-end simulation speedup, particularly
against direct evaluation of the unsplit full kernel. GPU execution untested.
