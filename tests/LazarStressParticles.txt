Lazar particle stress kernels
=============================
Implementation: include/DislocationDynamics/LazarStressParticleKernel.h
LazarStressParticleKernel<LazarPart::{full,shortRange,longRange}>.
Constructor arguments: shear modulus, Poisson ratio, physical length ell,
numerical screening length h. This implementation accepts h>=4*ell>0.
Six independent stress components; row-major source Q=b tensor t times line weight.
Uses the Helmholtz potential A=r+2ell^2(1-exp(-r/ell))/r and the rational screen
(1+2h^2 k^2)/(1+h^2 k^2)^2. No numerical convolution or line antiderivative.
Precomputed inverse lengths, screening prefactors, and Taylor coefficients.
Factored radial polynomials and four shared stress coefficients; six explicit
scalar stress contractions with one reciprocal radius and no temporary tensor.
Small-radius Taylor series and explicit radial derivatives. Scale separation
is checked once at construction; no h/ell-dependent branches or equal-length
fallbacks exist in particle evaluation. At exact coincidence
returns the odd-kernel principal value zero; the directional near-core limit
is finite but not zero. This convention needs to be retained when choosing
self quadrature. Production forces are NOT switched to these kernels.
The generic evaluateStressParticles Kokkos loop is shared with Cai;
evaluateCaiParticles remains as a compatible wrapper.

Validation: testLazarStressParticles checks independent long-double radial
derivatives, split reconstruction, rejection of insufficient scale separation, near-core
limits, classical far-field limit, oddness, parameter rejection, and Kokkos
versus host for all three kernels. testCaiStressParticles still passes.
No GPU backend is available on this machine: these are OpenMP CPU results.

Benchmark: benchmarkLazarStressParticles tutorial frame [targets=1024] [repeats=9].
Same saved polycrystal frames, source density 0.1, targets sampled at evenly
spaced array indices, and source/target arrays as benchmarkCaiStressParticles.
Cai a=2; Lazar ell=2, h=8 (Burgers units). Equal numerical core lengths do NOT
make the two physical core models equivalent, so their stress norms differ.
All source-target pairs, no cutoff, no periodic image sum, no FMM. Timings
exclude sampling/upload/download and initialization. Warmup followed by
11 repetitions per kernel; reported fenced medians. Kernels run consecutively.
Machine: Apple M2 Max, MacPorts Clang 20, optimized build, Kokkos OpenMP.
