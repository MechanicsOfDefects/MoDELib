Short-range particle neighbor search
====================================
Headers: include/FMM/ShortRangeParticleNeighbors.h and
include/FMM/KokkosShortRangeParticleNeighbors.h.

The host snapshot hashes original source IDs into Cartesian cells of side rc,
independent of the FMM depth. Each target searches nearby cells, retaining
only pairs with squared distance <= rc^2. CSR rows store (source ID,image ID),
with image translations stored once. Original particle order and tensor
weights are unchanged; the list introduces no network/topology modifications.
Neighbor rows are sorted by image/source for deterministic accumulation.

Pass mesh.periodicBasis() to enable exactly the active periodic directions.
An empty 3x0 basis selects free space. Image bounds are derived using the
left inverse of the periodic basis, the source/target bounding boxes, and rc.
This supports skew generators and more than one replica in a direction.
Dependent bases and impractically large image ranges throw; image ranges are
never silently truncated. No infinite long-range periodic sum is implemented.

The Kokkos evaluator reads uploaded CSR rows and rechecks the actual cutoff,
with one worker per target, six-component accumulation, no atomics. Upload
is blocking; evaluation is asynchronous until the caller fences/downloads.
The host list is a geometry snapshot: reconstruct it after ANY position,
ordering, or topology change, even if point counts are unchanged. Buffer
shape validation cannot detect same-size geometry changes. No stale-list
reuse or Verlet skin is implemented. Current benchmarks rebuild every call.
Production forces remain unchanged pending long-range FMM integration.

Tests: shortRangeParticleNeighbors compares every retained source-image
identity and resulting stress against an independent fixed replica cube.
Cases include 0/1/2/3 periodic directions, skew cells, opposite corners,
cutoffs larger than a cell, rebuilt moved targets, exact cutoff inclusion,
empty sets, zero cutoff and dependent-basis rejection. The Cai and Lazar
kernel regression tests also pass.

Benchmark target: benchmarkLazarNeighbors tutorial frame [targets=1024] [repeats=9]
Two modes: free space, then the actual mesh periodic basis. Same polycrystal
source and target sampling as prior benchmarks, ell=2,h=8,rc=12h=96.
12 OpenMP CPU threads, 1024 targets, 11 timed evaluations after warmup.
Build/upload are single timings; eval_median_ms is the fenced median. total_ms
adds build + upload + median evaluation. Original particle sampling and
source/target upload are excluded in both methods. brute_single_ms measures
one Kokkos all-pair scan with the same image shifts and distance cutoff.
The full short-range untruncated sum is NOT the reference here; cutoff error
was measured separately in LazarCutoff.txt. No FMM or long-range stress is
included in these timings. No GPU performance claims.
